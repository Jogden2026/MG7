# MG7
## Devlog
I started by making an array, GameObject[], which lets me apply my function to the birds looping on the Update. In each Update loop, I check the Vector3 of each bird and compare it to the player (Vector3.Distance). If it's below my set (and customizable) threshold, then the birds will pop out. Basically the array just allows me to check code on lots of objects at once.
